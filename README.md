# TshwaneConnect – Android Application

## Project Overview

**TshwaneConnect** is an Android mobile application developed by **Tech Unit**, a group of Software Development students at IIE Rosebank College, as part of the Work Integrated Learning (WIL) project.

The application is developed for **Tshwane Leadership Foundation (TLF)**, a South African non-profit organisation dedicated to building healthy and vibrant communities.

The project aims to support the organisation's internal operations by providing a digital platform for staff to access organisational information, manage programmes, and improve administrative processes.

## Project Objectives

- Develop a user-friendly Android mobile application.
- Provide secure registration and login functionality.
- Support internal staff operations.
- Improve access to organisational programmes and information.
- Support programme and case management.
- Implement database integration.
- Improve the efficiency of organisational administration.
- Provide a foundation for future system improvements.

## Planned System Features

The project requirements include:

- **User Authentication:** Registration, login, and logout.
- **Dashboard:** Central navigation to application features.
- **Programme Management:** View and manage TLF programmes.
- **Case Management:** Capture and manage beneficiary case information.
- **Staff Management:** Support authorised staff access.
- **Database Integration:** Store and retrieve application information.
- **Offline Support:** Support selected activities without an internet connection.
- **Role-Based Access:** Restrict functionality according to user permissions.

*Feature implementation and availability depend on the current development version.*

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/KgaogeloMokwena32/TshwaneConnect.git
```

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Allow Gradle to synchronise.
5. Connect a compatible Android device.
6. Build and run the application.
